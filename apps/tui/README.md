# @rp/tui — placeholder

Interactive terminal dashboard for Ranksta's Paradise. Built on
[`@opentui/core`](https://www.npmjs.com/package/@opentui/core), it renders one
site's dashboard and consumes the HTTP server through `@rp/api-client`.

This package is a skeleton stub for the Effect v4 monorepo rewrite (PLO-263).
The real TUI is ported in a later ticket; for now `src/main.ts` only logs.

Dependency graph: `tui → api-client → domain`.
